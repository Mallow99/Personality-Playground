# Avatar completion review

The owner approved all 54 suggested poses and identified the missing-layer defect.
This pass addresses that defect without replacing authored poses with a generic rig.

- Approval is recorded in `config/pose-approvals.json` and reflected in the gallery
  and runtime catalog. Local revision choices still override the review baseline.
- All 128 catalog entries are checked for actual browser image decoding. Source
  images, cutouts, IDs, reasons, and model tool selection remain available.
- Reading has a rear book surface beneath the hands. Business seated has a rear
  thigh beneath its resting hand. Reveal controls hide the front hands for inspection.
- The 126 other poses stay intact sprites. They are not animated through incomplete
  anatomical maps or described as fully layered models.
- The primary hosted entry opens the handler presentation. The 54-pose gallery has
  a dedicated approved-library page. The old rough mapping lab is archived.
- Handler colors, tools, reply cues, owner controls, overlay synchronization and
  both layered movements are covered by browser/backend checks. The local backend remains
  separate from the scripted hosted demonstration.

The optional native Windows host still needs validation on the actual PC. No Linux
browser test can establish Windows transparency, topmost, tray or click-through
behavior. Full-body model rigging remains a separate Later project. See HANDOFF.md
and avatar-runtime.md for launch instructions and remaining platform validation.

## Subsequent visual/control feedback

The owner correctly identified pale edges and ineffective controls despite the
previous checks. The Hide check had verified a state attribute rather than rendered
visibility. This pass removes the pale CSS glow, reverses white-matte edge blending
on all 54 cutouts, and fixes hiding in the shared renderer. A loading regression
check holds the SVG request while controls change, then verifies layer readiness.
Fifteen main work poses have local eye edits directed toward their props; originals
remain available. Other poses retain their authored gaze. Background choices and
explicit still/moving notes make the demo's actual capabilities inspectable.
See browser_avatar_controls.py and check_avatar_art.py for the new checks.

arm and a distorted hip/torso. A new reference was generated and directly traced;
both arms and hands are explicit. The rejected reference and source sheet remain.

and after repairs. The pass also found two neighboring-figure fragments in Hacker

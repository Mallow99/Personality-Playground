## Avoid a separate drawing for every application event

Waiting for the owner can reuse listening; clarification can reuse confused;
blocked work can use concerned; successful work can use celebrating or task complete;
quiet idle can alternate standing variants. Keep application state, personality,
and pose choice separate. The current studio is an interactive presentation proof,
not an autonomous job scheduler. Adult playful poses remain explicit manual choices.

## Body mapping and motion

Every pose has 17 stable anatomical/prop IDs. A hand retains its ID across poses,
even when arms cross. Guides mark hidden limbs rather than forcing them into view.
The studio can highlight, drag, translate, rotate, and export the pieces. Morphs
resample matching piece/color contours during movement, then restore complete
shapes. Subtle per-piece drift is independently switchable. Draft guide ownership
needs visual review; shape preservation does not prove perfect anatomy.

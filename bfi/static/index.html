CONNECTION & PROVENANCE

Know what’s answering.

This app makes no cloud delegation calls. A loopback address alone cannot prove that a model server runs entirely locally. Check your server’s settings.

To connect: edit .env, set BFI_BACKEND=openai, the /v1 endpoint, and model ID. Restart this app and start a new conversation. Model loading and unloading happen in your inference server.

REAL RESULTS, VISIBLE SOURCES

A small tool bench.

Set BFI_PROJECT_ROOT in .env to a project directory to enable read-only text files. Hidden, private/runtime directories, links, sensitive filenames, and large files are excluded. Review that directory before sharing it with a model. Set BFI_BRAVE_API_KEY for optional Brave web search. Restart after changes.

The checkboxes by the composer allow a real, compatible model up to three tool calls for that message only. They reset after sending. Mock mode cannot choose tools; this inspector can run configured tools directly. No computer control or code execution is implemented.
